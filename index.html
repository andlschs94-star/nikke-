BlablaLink 장비 자동 동기화

기업장비 현황을 계정에서 자동으로 가져옵니다.
최초 1회만 준비하면 됩니다.
  1. 브라우저에 Tampermonkey 같은 사용자 스크립트 확장 기능을 설치합니다.
  2. NIKKE Gear Manager 동기화 스크립트 설치를 엽니다.
  3. BlablaLink에 로그인되어 있는지 확인합니다.
  4. 아래 BlablaLink 열고 동기화 버튼을 누르면 새 창에서 계정 장비를 조회해 이 사이트로 반영합니다.
비밀번호·쿠키·토큰을 이 사이트에 입력하지 않습니다. 로그인 세션은 BlablaLink 쪽에서 사용되고, 동기화 결과에서 기업장비 타입만 받아옵니다.
