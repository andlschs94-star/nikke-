BlablaLink 장비 자동 동기화

기업장비 현황을 계정에서 자동으로 가져옵니다.
최초 1회만 준비하면 됩니다.
  1. Tampermonkey 설치를 먼저 설치합니다. 브라우저 확장프로그램
  2. NIKKE Gear Manager 동기화 스크립트 설치
  3. 원하는 계정 번호 계정 동기화 버튼 클릭
  4. 3-1. BlablaLink 로그인이 안되어 있다면 로그인 후 다시 동기화 버튼 클릭
  5. 아래에서 동기화할 계정을 직접 선택하면 해당 계정에만 장비를 반영합니다.
  6. 계정 이름 변경은 오른쪽 위 ⚙ 톱니바퀴 아이콘을 눌러 계정 이름을 수정한 뒤 저장합니다.
비밀번호·쿠키·토큰을 이 사이트에 입력하지 않습니다. 로그인 세션은 BlablaLink 쪽에서 사용되고, 동기화 결과에서 기업장비 타입만 받아옵니다.
